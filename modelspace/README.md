# 自由发 Freeflow · 网页版

多平台内容一键发布工具的网页版：一个页面写好内容，勾选平台，一键发布到 59 个平台。完全免费、开源；发布在你自己电脑上的浏览器里完成，账号与数据不经云端。

## 本 Space 是什么

这是[自由发](https://github.com/xingguangYan/freeflow)网页版的公开入口，由 Gradio 以静态方式托管（`web/` 目录），不经过任何后端服务。

- 已在电脑上运行桌面版：在页面顶部地址栏填入引擎地址（本机 `http://localhost:8917`，局域网 `http://<电脑IP>:8917`），点「连接引擎」即可一键发布
- 还没有桌面版：先当成在线写作工具用，草稿保存在本浏览器，可导出 Markdown / HTML；要发布请[下载桌面版](https://github.com/xingguangYan/freeflow/releases/latest)（免费、绿色免安装）
